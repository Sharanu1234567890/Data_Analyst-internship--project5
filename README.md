# Data_Analyst-internship--project5

## Summary of Findings:

1. **Sex and Survival**: Females had significantly higher survival rates.
2. **Class and Survival**: Passengers in 1st class had the highest survival.
3. **Fare**: Higher fare passengers generally had better survival odds.
4. **Age**: Younger passengers had a slightly better survival rate.
5. **Missing Data**: 'Cabin' was dropped due to many nulls; 'Age' and 'Embarked' were imputed.
6. **Correlation**: Fare and Pclass had the strongest inverse relationship.

These insights can help guide predictive modeling and feature engineering.
